# Mottelo — pages légales

Pages statiques pour GitHub Pages. Aucun outil de build : il suffit d'envoyer ces fichiers à la racine du dépôt.

## Fichiers
- `index.html` : accueil et liens
- `privacy-policy.html` : politique de confidentialité
- `terms.html` : conditions générales d'utilisation (CGU)
- `sales-terms.html` : conditions de vente
- `account-deletion.html` : suppression du compte
- `data-safety.html` : résumé « sécurité des données »
- `legal-notice.html` : mentions légales
- `style.css`, `logo.png` : mise en page (partagée par toutes les pages)

## Mettre en ligne
1. Dans votre dépôt GitHub Pages, remplacez les anciens fichiers par ceux-ci (même noms).
2. Faites un commit sur la branche publiée (Settings > Pages).
3. Attendez 1 à 2 minutes puis rechargez les pages (Ctrl+F5).

## Dans la Google Play Console
- URL de la politique de confidentialité : `.../privacy-policy.html`
- URL de suppression de compte : `.../account-deletion.html`
